# 反汇编地址与原始数据复核索引

地址说明：

- KEY 地址按应用链接基址 `0x4000` 表示；
- BLE 地址为 CC254x/8051 镜像代码地址；
- `文件偏移` 直接对应固件容器中的字节位置；
- 地址用于复核官方二进制，不应直接复制为 C18 源码中的硬编码调用。

| 行表 | RAM `0x200001B0` | GPIO 基址 + 位掩码 |
| 列表 | RAM `0x200001D8` | GPIO 基址 + 位掩码 |

## 复核结论

能够直接从上述索引建立的 C18 KEY 改造要求：

1. 保持 C18 板级地址和 GPIO。
2. 复用共同 BLE UART 和基础帧族。
3. 移植 AP2D 完整帧、长度和序号处理原则。
4. 兼容 LED Output 1 B/2 B。
5. 为 BLE 2.13 提供 Consumer 8 B 编码。
6. 为 BLE 2.13 交换 Vendor 逻辑方向。
7. 采用四槽异步事件投递，修复只清 pending flag 的模式。
8. 按 C18 LED MCU/USB/矩阵重写 suspend。
